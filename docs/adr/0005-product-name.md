# ADR 0005: Product name
Status: accepted (chosen by John, 2026-11-06)

Name: **Tidewatch**. Hosts rise and fall with hibernate and scaling like a tide, and the product watches over them. Alternatives considered: Pulseline, Vantage, Beacon.

Checks done: a web search found no existing Azure Virtual Desktop product with this name. This is NOT a trademark clearance. Before public launch, Pricing & Sales Lead to arrange a trademark search (IP Australia and USPTO), check the domain and social handles, and check the Azure Marketplace.

Rule: the name lives only in `apps/web/src/lib/product.ts`, `README.md` and these docs, so a rename stays a one-line change.
